## ในบทนี้คุณจะได้เรียนอะไร

หลังจบบทนี้ คุณจะ

- เข้าใจว่าทำไมต้องมีลูป และเลือกใช้ `for` / `while` / `do-while` ให้เหมาะกับงาน
- อ่านและเขียน `for` loop ได้คล่อง รู้ว่าแต่ละส่วนในวงเล็บทำหน้าที่อะไร
- ใช้รูปแบบ **accumulator** (สะสมค่า) เพื่อหาผลรวม ผลคูณ และการนับ
- เขียนลูปซ้อนลูป (nested loop) เพื่อวาดรูปและตาราง
- ควบคุมลูปด้วย `break` และ `continue`
- รู้จักบั๊กคลาสสิก off-by-one และลูปไม่รู้จบ

> 📝 **ใช้เวลาประมาณ 30 นาที** ลูปคือพลังที่ทำให้คอมพิวเตอร์ต่างจากเราจริงๆ คือทำงานซ้ำๆ เป็นล้านรอบได้โดยไม่เบื่อ

## ทำไมต้องมีลูป

สมมติต้องพิมพ์ข้อความ "Round 1" ถึง "Round 5" ถ้าไม่มีลูป เราต้องเขียน `println` ห้าบรรทัด แล้วถ้าเป็น 1,000 รอบล่ะ? เขียนมือไม่ไหวแน่ ลูปคือคำสั่งให้ **ทำโค้ดชุดเดิมซ้ำ** ตามเงื่อนไขที่เรากำหนด

## `for` loop

ใช้เมื่อ **รู้จำนวนรอบล่วงหน้า** (หรือรู้ช่วงที่จะวน) รูปแบบ

```java run=no
for (ตัวเริ่มต้น; เงื่อนไขทำต่อ; ตัวปรับค่า) {
    // โค้ดที่ทำซ้ำในแต่ละรอบ
}
```

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println("Round " + i);
        }
    }
}
```

```output
Round 1
Round 2
Round 3
Round 4
Round 5
```

ในวงเล็บของ `for` มี 3 ส่วนคั่นด้วย `;`

| ส่วน | โค้ดในตัวอย่าง | ทำงานเมื่อไร |
|---|---|---|
| **1. ตัวเริ่มต้น** | `int i = 1` | ทำ **ครั้งเดียว** ตอนเริ่มลูป สร้างตัวนับ `i` เริ่มที่ 1 |
| **2. เงื่อนไขทำต่อ** | `i <= 5` | ตรวจ **ก่อนทุกรอบ** ถ้าเป็นจริงก็ทำรอบนี้ ถ้าเท็จก็ออกจากลูป |
| **3. ตัวปรับค่า** | `i++` | ทำ **หลังจบทุกรอบ** เพิ่ม i ทีละ 1 |

ลองไล่ดูว่าคอมพิวเตอร์ทำอะไรบ้างทีละขั้น (ตารางนี้เรียกว่า *trace table* เป็นเครื่องมือที่โปรแกรมเมอร์ใช้ไล่ความคิด)

| รอบ | ค่า `i` ตอนตรวจ | `i <= 5` | พิมพ์ | หลังรอบ `i++` |
|---|---|---|---|---|
| 1 | 1 | จริง | Round 1 | i = 2 |
| 2 | 2 | จริง | Round 2 | i = 3 |
| 3 | 3 | จริง | Round 3 | i = 4 |
| 4 | 4 | จริง | Round 4 | i = 5 |
| 5 | 5 | จริง | Round 5 | i = 6 |
| (จบ) | 6 | **เท็จ** | ออกจากลูป | |

> 💡 **เคล็ดลับ:** ตัวนับในลูปตั้งชื่ออะไรก็ได้ แต่ธรรมเนียมคือ `i`, `j`, `k` ตัวแปรที่ประกาศในวงเล็บ `for` จะ **ใช้ได้เฉพาะในลูปนั้น** พอลูปจบตัวแปรก็หายไป

### ปรับแต่งทิศทางและขนาดก้าว

เปลี่ยนส่วนที่ 1-3 ก็ได้ลูปแบบอื่นทันที เช่น นับถอยหลัง หรือนับข้ามทีละ 2

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 5; i >= 1; i--) {
            System.out.print(i + " ");
        }
        System.out.println("Go!");

        for (int i = 0; i <= 10; i += 2) {
            System.out.print(i + " ");
        }
        System.out.println();
    }
}
```

```output
5 4 3 2 1 Go!
0 2 4 6 8 10
```

## รูปแบบ Accumulator: สะสมค่าไปเรื่อยๆ

ลูปส่วนใหญ่ในชีวิตจริงใช้ **ตัวแปรสะสมค่า** ที่สร้างไว้ **นอกลูป** แล้วค่อยๆ ปรับค่าในแต่ละรอบ รูปแบบนี้ใช้บ่อยจนต้องจำให้ขึ้นใจ สำหรับ **หาผลรวม**

```java
public class Main {
    public static void main(String[] args) {
        int sum = 0;                       // 1) ตั้งค่าเริ่มต้นนอกลูป
        for (int i = 1; i <= 10; i++) {
            sum = sum + i;                 // 2) สะสมค่าในแต่ละรอบ
        }
        System.out.println("Sum = " + sum); // 3) ใช้ผลลัพธ์หลังลูปจบ
    }
}
```

```output
Sum = 55
```

ไล่ค่าของ `sum` ในแต่ละรอบ (แสดงแค่ 4 รอบแรก)

| รอบ | `i` | `sum` ก่อนบวก | `sum = sum + i` | `sum` หลังบวก |
|---|---|---|---|---|
| 1 | 1 | 0 | 0 + 1 | 1 |
| 2 | 2 | 1 | 1 + 2 | 3 |
| 3 | 3 | 3 | 3 + 3 | 6 |
| 4 | 4 | 6 | 6 + 4 | 10 |
| ... | ... | ... | ... | จนถึงรอบ 10 ได้ **55** |

> ⚠️ **จุดที่มือใหม่พลาดบ่อย:** ต้องตั้งค่าเริ่มต้นของ `sum` เป็น `0` **นอกลูป** ถ้าไปประกาศ `int sum = 0;` ไว้ข้างในลูป ค่าจะถูกรีเซ็ตเป็น 0 ทุกรอบ

รูปแบบเดียวกันใช้ได้กับงานอื่น เพียงเปลี่ยนค่าเริ่มต้นกับการสะสม

| งาน | ค่าเริ่มต้น | ในแต่ละรอบ |
|---|---|---|
| ผลรวม | `0` | `sum += i;` |
| ผลคูณ (เช่น แฟกทอเรียล) | `1` (ไม่ใช่ 0!) | `result *= i;` |
| นับจำนวน | `0` | `if (เงื่อนไข) { count++; }` |

```java
public class Main {
    public static void main(String[] args) {
        int result = 1;
        for (int i = 1; i <= 5; i++) {
            result *= i;
        }
        System.out.println("5! = " + result);

        int count = 0;
        for (int i = 1; i <= 20; i++) {
            if (i % 3 == 0) {
                count++;
            }
        }
        System.out.println("Multiples of 3 up to 20: " + count);
    }
}
```

```output
5! = 120
Multiples of 3 up to 20: 6
```

ตัวอย่างที่สองนับจำนวนทวีคูณของ 3 ตั้งแต่ 1 ถึง 20 (ได้แก่ 3, 6, 9, 12, 15, 18 รวม 6 ตัว) เป็นการเอา `if` จากบทที่แล้วมาผสมกับลูป ซึ่งเป็นสูตรที่ใช้บ่อยมาก

## `while` loop

`while` เหมาะเมื่อ **ไม่รู้จำนวนรอบล่วงหน้า** แต่รู้ว่าจะทำต่อ *ตราบใดที่* เงื่อนไขยังเป็นจริง

```java
public class Main {
    public static void main(String[] args) {
        int n = 1;
        while (n <= 5) {
            System.out.println(n);
            n++;
        }
    }
}
```

```output
1
2
3
4
5
```

ผลเหมือน `for` แต่สังเกตว่าเราต้อง **ตั้งค่าเริ่มต้นเอง** ก่อนลูป (`int n = 1`) และ **ปรับค่าเองในลูป** (`n++`) ถ้าลืมบรรทัด `n++` ค่า n จะไม่เปลี่ยนเลย เงื่อนไขจริงตลอดไป และโปรแกรมจะวนไม่รู้จบ

ตัวอย่างที่ `while` เหมาะกว่า: นับจำนวนหลักของเลขจำนวนเต็ม เราไม่รู้ล่วงหน้าว่าต้องหารกี่รอบ แต่รู้ว่าให้หารด้วย 10 ไปเรื่อยๆ จนเหลือ 0

```java stdin=12345
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int digits = 0;
        while (n > 0) {
            n = n / 10;     // ตัดหลักสุดท้ายทิ้ง (จำการหารจำนวนเต็มได้ไหม?)
            digits++;
        }
        System.out.println("Digits: " + digits);
    }
}
```

```output
Digits: 5
```

12345 → 1234 → 123 → 12 → 1 → 0 หารไป 5 รอบจึงถึง 0 นั่นคือมี 5 หลัก

### `do-while`: ทำก่อนแล้วค่อยตรวจ

`do-while` ต่างจาก `while` ตรงที่ **ตรวจเงื่อนไขท้ายลูป** ดังนั้นโค้ดข้างในจะ **ทำอย่างน้อย 1 รอบเสมอ** แม้เงื่อนไขจะเป็นเท็จตั้งแต่แรก ใช้เมื่อต้องการ "ทำก่อนอย่างน้อยหนึ่งครั้ง" เช่น แสดงเมนูแล้วถามว่าจะทำต่อไหม

```java
public class Main {
    public static void main(String[] args) {
        int i = 10;
        do {
            System.out.println("Runs once, i = " + i);
            i++;
        } while (i < 5);
    }
}
```

```output
Runs once, i = 10
```

เงื่อนไข `i < 5` เป็นเท็จตั้งแต่ต้น แต่ยังได้ทำ 1 รอบ ถ้าเป็น `while` ธรรมดาจะไม่ทำเลย

| ลูป | ตรวจเงื่อนไขเมื่อไร | ใช้เมื่อ |
|---|---|---|
| `for` | ก่อนทุกรอบ | รู้จำนวนรอบ / วนตามช่วงตัวเลข |
| `while` | ก่อนทุกรอบ | ไม่รู้จำนวนรอบ ทำตราบใดที่เงื่อนไขจริง |
| `do-while` | หลังทุกรอบ | ต้องทำอย่างน้อย 1 รอบ |

## ลูปซ้อนลูป (Nested Loop)

ลูปข้างในลูปได้ ลูปด้านนอกทำ 1 รอบ ลูปด้านในจะทำ **ครบทั้งหมด** ก่อนที่ลูปนอกจะขยับไปรอบถัดไป เหมือนเข็มนาทีกับเข็มชั่วโมง ใช้วาดรูปและทำตาราง

```java
public class Main {
    public static void main(String[] args) {
        for (int row = 1; row <= 4; row++) {
            for (int col = 1; col <= row; col++) {
                System.out.print("*");
            }
            System.out.println();   // จบแถว ขึ้นบรรทัดใหม่
        }
    }
}
```

```output
*
**
***
****
```

แถวที่ 1 ลูปในวน 1 รอบ แถวที่ 2 วน 2 รอบ... เพราะเงื่อนไข `col <= row` ผูกกับแถวปัจจุบัน และ `println()` เปล่าๆ ที่อยู่ในลูปนอก ทำหน้าที่ขึ้นบรรทัดใหม่เมื่อจบแต่ละแถว

ตารางสูตรคูณ 3 x 3

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                System.out.print(i * j + " ");
            }
            System.out.println();
        }
    }
}
```

```output
1 2 3
2 4 6
3 6 9
```

## `break` และ `continue`

| คำสั่ง | ทำอะไร |
|---|---|
| `break` | **ออกจากลูปทันที** (เลิกวนทั้งหมด) |
| `continue` | **ข้ามส่วนที่เหลือของรอบนี้** แล้วไปรอบถัดไป |

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i == 3) {
                continue;   // ข้ามเลข 3
            }
            if (i == 6) {
                break;      // หยุดทั้งลูปเมื่อถึง 6
            }
            System.out.print(i + " ");
        }
        System.out.println();
    }
}
```

```output
1 2 4 5
```

เลข 3 ถูกข้ามด้วย `continue` และพอถึง 6 ลูปหยุดทั้งหมดด้วย `break` จึงไม่ได้พิมพ์ 6-10

## ข้อผิดพลาดที่เจอบ่อย

**1. Off-by-one error** คือวนเกินหรือขาดไป 1 รอบ เกิดจากเลือก `<` หรือ `<=` ผิด

| เขียนว่า | วนกี่รอบ | ค่าที่ได้ |
|---|---|---|
| `for (int i = 1; i <= 5; i++)` | 5 รอบ | 1, 2, 3, 4, 5 |
| `for (int i = 1; i < 5; i++)` | 4 รอบ | 1, 2, 3, 4 |
| `for (int i = 0; i < 5; i++)` | 5 รอบ | 0, 1, 2, 3, 4 (นิยมใช้กับ array) |

**2. ลูปไม่รู้จบ (infinite loop)** เกิดเมื่อเงื่อนไขไม่มีวันเป็นเท็จ เช่น ลืมปรับตัวนับ หรือปรับผิดทิศ

```java run=no
int i = 1;
while (i <= 5) {
    System.out.println(i);
    // ลืม i++ -> i เป็น 1 ตลอดไป พิมพ์ 1 ไม่หยุด!
}
```

> ⚠️ **ถ้าโค้ดค้างใน Playground:** ระบบรันโค้ดจะ *ตัดการทำงานเองเมื่อรันนานเกินกำหนด* และแจ้งข้อความว่าโค้ดทำงานนานเกินไป ไม่ต้องตกใจ แก้เงื่อนไขหรือตัวนับแล้วรันใหม่ได้เลย

**3. ประกาศตัวสะสมไว้ในลูป** ทำให้ถูกรีเซ็ตทุกรอบ (ดูหัวข้อ accumulator ด้านบน)

> 4. อ่านเลข N แล้วพิมพ์สามเหลี่ยมดาวสูง N แถว

## สรุปบทที่ 4

| เรื่อง | สิ่งที่ต้องจำ |
|---|---|
| `for` | `for (เริ่มต้น; เงื่อนไข; ปรับค่า)` ใช้เมื่อรู้จำนวนรอบ |
| `while` | ทำตราบใดที่เงื่อนไขเป็นจริง ใช้เมื่อไม่รู้จำนวนรอบ |
| `do-while` | ทำก่อนแล้วตรวจ ทำอย่างน้อย 1 รอบ |
| Accumulator | ตั้งค่าเริ่มต้น **นอกลูป** (ผลรวม=0, ผลคูณ=1) แล้วสะสมในลูป |
| ลูปซ้อน | ลูปในทำครบก่อนลูปนอกจะขยับ ใช้วาดรูป/ตาราง |
| `break` / `continue` | ออกจากลูป / ข้ามรอบนี้ |
| ระวัง | off-by-one (`<` vs `<=`), ลูปไม่รู้จบ, ประกาศตัวสะสมในลูป |

ถัดไปลองทำแบบฝึกหัดหาผลรวม 1 ถึง N ได้เลย ใช้รูปแบบ accumulator ที่เพิ่งเรียนมานี่แหละ
