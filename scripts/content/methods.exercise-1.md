## prompt

เติมเมธอด `sum(int a, int b)` ให้ **คืนค่าผลบวก** ของ a และ b โค้ดตั้งต้นอ่านเลขสองจำนวน (คนละบรรทัด) แล้วเรียก `sum(a, b)` พิมพ์ผลลัพธ์ให้เรียบร้อยแล้ว หน้าที่ของคุณคือแก้ **ตัวเมธอด `sum`** ให้ถูกต้อง

**ตัวอย่าง**

| Input (คนละบรรทัด) | ผลลัพธ์ที่ต้องได้ |
|---|---|
| `3` `4` | `7` |
| `10` `25` | `35` |

## hint

ตอนนี้เมธอด `sum` เขียนว่า `return 0;` ทำให้ได้ 0 เสมอ ให้เปลี่ยนเป็น `return a + b;` (ส่งค่าผลบวกของพารามิเตอร์ทั้งสองกลับไป)

## explanation

```java run=no
static int sum(int a, int b) {
    return a + b;
}
```

- `int` หน้าชื่อเมธอด บอกว่าเมธอดนี้ **ส่งค่า `int` กลับ** ดังนั้นต้อง `return` ค่า `int` เสมอ
- `a` และ `b` คือพารามิเตอร์ ซึ่งรับค่าที่ส่งมาตอนเรียก `sum(a, b)` ใน `main`
- `return a + b;` คำนวณผลบวกแล้วส่งกลับ ไปแทนที่ `sum(a, b)` ใน `System.out.println(sum(a, b))`
- สังเกตว่า `main` ไม่ต้องรู้เลยว่า `sum` คำนวณอย่างไร รู้แค่ว่าส่งเลขสองตัวไป จะได้ผลบวกกลับมา นี่คือประโยชน์ของการแบ่งงานเป็นเมธอด
