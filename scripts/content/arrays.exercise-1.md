## prompt

อ่านจำนวนเต็ม **5 ค่า** (คนละบรรทัด รวม 5 บรรทัด) เก็บเข้า array แล้วพิมพ์ **ค่าที่มากที่สุด**

โค้ดตั้งต้นอ่านค่าเข้า array ให้แล้ว หน้าที่ของคุณคือหาค่ามากที่สุดและพิมพ์ผลลัพธ์

**ตัวอย่าง**

| Input (คนละบรรทัด) | ผลลัพธ์ที่ต้องได้ |
|---|---|
| `3` `7` `2` `9` `5` | `9` |
| `10` `20` `5` `1` `8` | `20` |

## hint

สร้างตัวแปร `max` เก็บค่ามากที่สุดที่เจอ เริ่มด้วย `int max = numbers[0];` แล้วใช้ `for` ไล่ตั้งแต่ `i = 1` ถึง `i < numbers.length` ถ้า `numbers[i] > max` ให้อัปเดต `max = numbers[i];` เมื่อจบลูปค่อย `println(max)`

## explanation

```java run=no
int max = numbers[0];
for (int i = 1; i < numbers.length; i++) {
    if (numbers[i] > max) {
        max = numbers[i];
    }
}
System.out.println(max);
```

- **สมมติตัวแรกมากสุดไปก่อน** (`max = numbers[0]`) แล้วไล่เทียบตัวที่เหลือ
- ลูปเริ่มที่ `i = 1` เพราะตัวที่ 0 เอามาเป็นค่าเริ่มต้นไปแล้ว ไม่ต้องเทียบกับตัวเอง
- เจอตัวที่ใหญ่กว่า `max` ที่จำไว้ ก็เปลี่ยนค่า `max` เป็นตัวใหม่
- เมื่อไล่ครบทุกตัว `max` จะเก็บค่าที่ใหญ่ที่สุดไว้
- เงื่อนไขลูป `i < numbers.length` ใช้ `<` เพราะ index สุดท้ายคือ `length - 1`

**ทำไมไม่เริ่ม `max = 0`?** ถ้าทุกตัวเป็นเลขติดลบ คำตอบจะผิดเป็น 0 ทั้งที่ 0 ไม่อยู่ใน array
