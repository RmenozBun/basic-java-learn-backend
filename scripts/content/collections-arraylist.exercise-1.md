## prompt

อ่านจำนวนเต็ม **N** แล้วตามด้วยตัวเลข **N ค่า** (คนละบรรทัด) เก็บลง `ArrayList<Integer>` จากนั้นพิมพ์ **ผลรวมเฉพาะเลขคู่**

โค้ดตั้งต้นอ่านข้อมูลเข้า `numbers` ให้แล้ว หน้าที่ของคุณคือรวมเฉพาะเลขคู่เข้า `sum`

**ตัวอย่าง**

| Input (คนละบรรทัด) | ผลลัพธ์ที่ต้องได้ | อธิบาย |
|---|---|---|
| `5` `1` `2` `3` `4` `5` | `6` | เลขคู่คือ 2 กับ 4 รวมกันได้ 6 |
| `4` `2` `4` `6` `8` | `20` | ทุกตัวเป็นเลขคู่ รวมได้ 20 |

## hint

วนลูปด้วย for-each: `for (int num : numbers) { ... }` ข้างในใช้ `if (num % 2 == 0)` ตรวจเลขคู่ ถ้าใช่ก็สั่ง `sum = sum + num;`

## explanation

```java run=no
for (int num : numbers) {
    if (num % 2 == 0) {
        sum = sum + num;
    }
}
```

- `for (int num : numbers)` วนอ่านสมาชิกของ `ArrayList` ทีละตัว (ได้เหมือนกับ array) โดย `num` เป็น `int` ที่ Java แปลงจาก `Integer` ให้เองอัตโนมัติ
- `num % 2 == 0` ตรวจว่าเป็นเลขคู่หรือไม่ (จากบทเงื่อนไข)
- ตัวสะสม `sum` ตั้งเป็น 0 ไว้ก่อนลูป (จากบทลูป) แล้วบวกเฉพาะเลขที่ผ่านเงื่อนไข
- ข้อนี้รวมความรู้หลายบทเข้าด้วยกัน: Scanner + ลูป + เงื่อนไข + `%` + ArrayList คือภาพจำลองของโปรแกรมจริงที่ผสมเครื่องมือหลายอย่างเข้าด้วยกัน
