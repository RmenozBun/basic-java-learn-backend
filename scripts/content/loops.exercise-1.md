## prompt

อ่านจำนวนเต็ม **N** แล้วพิมพ์ **ผลรวมของเลข 1 ถึง N** (นับรวม N)

**ตัวอย่าง**

| Input | ผลลัพธ์ที่ต้องได้ | อธิบาย |
|---|---|---|
| `5` | `15` | 1 + 2 + 3 + 4 + 5 = 15 |
| `10` | `55` | 1 + 2 + ... + 10 = 55 |

## hint

ใช้รูปแบบ accumulator จากบทเรียน: ตัวแปร `sum` ถูกตั้งเป็น 0 ไว้ให้แล้ว ให้เขียน `for` loop ให้ `i` วิ่งจาก 1 ถึง `n` (ใช้ `<=`) แล้วทุกรอบสั่ง `sum = sum + i;`

## explanation

```java run=no
for (int i = 1; i <= n; i++) {
    sum = sum + i;
}
```

- ตัวสะสม `sum` ถูกประกาศและตั้งเป็น `0` **นอกลูป** (ในโค้ดตั้งต้น) ถ้าตั้งในลูปจะถูกรีเซ็ตทุกรอบ
- `i` เริ่มที่ 1 และวนต่อตราบใดที่ `i <= n` เราใช้ `<=` เพราะต้องรวม n ด้วย (ถ้าใช้ `<` จะขาด n ไปหนึ่งตัว นี่คือบั๊ก off-by-one)
- แต่ละรอบเอา `i` มาบวกสะสมเข้า `sum`
- หลังลูปจบ `sum` เก็บผลรวมทั้งหมด แล้วบรรทัดสุดท้ายของโค้ดตั้งต้นพิมพ์ออกมา

**ของแถม:** มีสูตรลัด `n * (n + 1) / 2` ที่ให้ผลเท่ากันโดยไม่ต้องใช้ลูป แต่เป้าหมายของข้อนี้คือฝึกรูปแบบ accumulator ที่ใช้ได้กับปัญหาอื่นอีกมากมาย
