## ในบทนี้คุณจะได้เรียนอะไร

หลังจบบทนี้ คุณจะ

- เข้าใจว่า **ตัวแปร** คืออะไร และใช้เก็บข้อมูลอย่างไร
- รู้จักชนิดข้อมูลพื้นฐาน `int`, `double`, `char`, `boolean`, `String` และเลือกใช้ให้ถูก
- ตั้งชื่อตัวแปรตามกฎและธรรมเนียมของ Java
- ใช้ตัวดำเนินการคำนวณ `+ - * / %` และรู้กับดักของการหารเลขจำนวนเต็ม
- แปลงชนิดข้อมูล (casting) ได้
- รับข้อมูลจากผู้ใช้ด้วย `Scanner` และไม่ตกหลุมพราง `nextInt()` ตามด้วย `nextLine()`

> 📝 **ใช้เวลาประมาณ 25 นาที** บทนี้เป็นพื้นฐานที่สำคัญที่สุดของทั้งคอร์ส ถ้าเข้าใจตัวแปรแล้ว บทหลังๆ จะง่ายขึ้นมาก

## ตัวแปรคืออะไร

โปรแกรมต้องจำข้อมูลบางอย่างไว้ใช้ เช่น ชื่อผู้เล่น คะแนนปัจจุบัน หรืออายุของผู้ใช้ **ตัวแปร (variable)** คือ "กล่องที่มีป้ายชื่อติดอยู่" ที่ใช้เก็บข้อมูลหนึ่งชิ้นไว้ในหน่วยความจำของคอมพิวเตอร์

```diagram
   +---------+        +----------+        +------------+
   |   19    |        |   3.75   |        |   "Ploy"   |
   +---------+        +----------+        +------------+
   age (int)          gpa (double)        name (String)
```

ตัวแปรทุกตัวมี 3 อย่าง คือ **ชนิดข้อมูล** (กล่องนี้ใส่อะไรได้) **ชื่อ** (ป้ายที่ติดไว้ให้เรียกใช้) และ **ค่า** (ของที่อยู่ในกล่องตอนนี้) และสิ่งที่ทำให้ตัวแปรเป็น "ตัวแปร" ก็คือ **ค่าของมันเปลี่ยนได้** ระหว่างที่โปรแกรมทำงาน

## ชนิดข้อมูลพื้นฐาน

Java เป็นภาษาที่ **ต้องบอกชนิดข้อมูลทุกครั้งที่สร้างตัวแปร** คอมไพเลอร์จะได้รู้ว่าต้องจองที่ในหน่วยความจำเท่าไร และใช้ตัวแปรนั้นผิดวิธีหรือเปล่า

| ชนิด | เก็บอะไร | ตัวอย่างค่า |
|---|---|---|
| `int` | จำนวนเต็ม (ประมาณ -2.1 พันล้าน ถึง 2.1 พันล้าน) | `19`, `-5`, `0` |
| `long` | จำนวนเต็มขนาดใหญ่มาก | `9000000000L` |
| `double` | เลขทศนิยม | `3.75`, `-0.5` |
| `char` | ตัวอักษร **1 ตัว** ใช้ `' '` ครอบ | `'A'`, `'7'` |
| `boolean` | ค่าจริง/เท็จ มีแค่ 2 ค่า | `true`, `false` |
| `String` | ข้อความ ใช้ `" "` ครอบ | `"Ploy"`, `"Hello"` |

> 📝 `String` ไม่ใช่ชนิดข้อมูลพื้นฐานจริงๆ แต่เป็น *คลาส* ที่ Java เตรียมไว้ให้ (ขึ้นต้นด้วยตัวพิมพ์ใหญ่ ต่างจากชนิดอื่น) ตอนนี้ใช้ได้เหมือนชนิดข้อมูลปกติไปก่อนเลย จะได้เรียนละเอียดในบท OOP

### ประกาศและใช้ตัวแปร

รูปแบบ: `ชนิด ชื่อ = ค่า;` อ่านว่า "สร้างกล่องชนิด... ชื่อ... แล้วใส่ค่า... ลงไป" เครื่องหมาย `=` ใน Java **ไม่ได้แปลว่า "เท่ากับ"** แต่แปลว่า **"เอาค่าทางขวาไปเก็บไว้ในตัวแปรทางซ้าย"**

```java
public class Main {
    public static void main(String[] args) {
        int age = 19;
        double gpa = 3.75;
        char grade = 'A';
        boolean isStudent = true;
        String name = "Ploy";

        System.out.println(name);
        System.out.println(age);
        System.out.println(gpa);
        System.out.println(grade);
        System.out.println(isStudent);
    }
}
```

```output
Ploy
19
3.75
A
true
```

สังเกตว่า `System.out.println(name)` ไม่มีเครื่องหมายคำพูด เพราะเราไม่ได้ต้องการพิมพ์คำว่า "name" แต่ต้องการพิมพ์ **ค่าที่อยู่ในตัวแปรชื่อ name** (ซึ่งคือ Ploy) ถ้าใส่เครื่องหมายคำพูดจะพิมพ์คำว่า name ตรงๆ แทน

### เปลี่ยนค่าของตัวแปร

ตัวแปรจะประกาศก่อนแล้วค่อยใส่ค่าทีหลังก็ได้ และเปลี่ยนค่าได้เรื่อยๆ ค่าใหม่จะ **ทับ** ค่าเก่าทันที

```java
public class Main {
    public static void main(String[] args) {
        int score;          // ประกาศก่อน (ยังไม่มีค่า)
        score = 10;         // ใส่ค่าครั้งแรก
        System.out.println(score);

        score = 25;         // เปลี่ยนค่า ค่า 10 ถูกทับหายไป
        System.out.println(score);

        score = score + 5;  // เอาค่าเดิม (25) มาบวก 5 แล้วเก็บกลับเข้าตัวแปรเดิม
        System.out.println(score);
    }
}
```

```output
10
25
30
```

บรรทัด `score = score + 5;` ทำให้คนที่เคยเรียนคณิตศาสตร์งงได้ เพราะในทางคณิตศาสตร์ x = x + 5 เป็นไปไม่ได้ แต่ในโปรแกรมมันอ่านว่า **"ไปหยิบค่าใน score มาบวก 5 ได้ผลเท่าไรก็เก็บกลับเข้า score"** ซึ่งเป็นรูปแบบที่ใช้บ่อยมากๆ

### กฎการตั้งชื่อตัวแปร

| กฎ | ตัวอย่างที่ถูก | ตัวอย่างที่ผิด |
|---|---|---|
| ใช้ได้เฉพาะตัวอักษร ตัวเลข `_` และ `$` | `score1`, `my_age` | `my-age`, `my age` |
| ห้ามขึ้นต้นด้วยตัวเลข | `item2` | `2item` |
| ห้ามซ้ำกับคำสงวนของ Java | `total` | `class`, `int`, `public` |
| แยกตัวพิมพ์เล็ก-ใหญ่ | `Score` และ `score` คือคนละตัว | |

ธรรมเนียมที่โปรแกรมเมอร์ Java ทุกคนใช้คือ **camelCase** ขึ้นต้นด้วยตัวพิมพ์เล็ก และคำถัดไปขึ้นต้นด้วยตัวพิมพ์ใหญ่ เช่น `studentName`, `totalScore`, `isFinished` และตั้งชื่อให้ **สื่อความหมาย** เช่น `age` ดีกว่า `a` และ `totalPrice` ดีกว่า `x`

## ต่อข้อความด้วย `+`

เครื่องหมาย `+` กับ String คือการ **ต่อข้อความ** (concatenation) ใช้ผสมข้อความกับค่าของตัวแปรเป็นประโยคเดียวได้

```java
public class Main {
    public static void main(String[] args) {
        String name = "Ploy";
        int age = 19;
        System.out.println("Name: " + name);
        System.out.println("Age: " + age + " years old");
        System.out.println(name + " is " + age);
    }
}
```

```output
Name: Ploy
Age: 19 years old
Ploy is 19
```

> ⚠️ **กับดักที่ควรรู้:** Java คำนวณ `+` จากซ้ายไปขวาทีละคู่ ถ้าซ้ายมือเป็นตัวเลขทั้งคู่จะ **บวกเลข** แต่ถ้ามี String อยู่ด้านใดด้านหนึ่งจะ **ต่อข้อความ** ผลลัพธ์จึงต่างกันตามลำดับ ลองเดาก่อนกดรันว่าแต่ละบรรทัดได้อะไร

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(1 + 2 + "x");
        System.out.println("x" + 1 + 2);
        System.out.println("x" + (1 + 2));
    }
}
```

```output
3x
x12
x3
```

บรรทัดแรก `1 + 2` คำนวณก่อนได้ 3 แล้วค่อยต่อกับ "x" เป็น `3x` บรรทัดที่สอง `"x" + 1` ได้ข้อความ `x1` ก่อน แล้วต่อ `2` ได้ `x12` บรรทัดที่สามใส่วงเล็บบังคับให้บวกเลขก่อน เป็น `x3` **วงเล็บคือเครื่องมือควบคุมลำดับการคำนวณ**

## ตัวดำเนินการคำนวณ

| ตัวดำเนินการ | ความหมาย | ตัวอย่าง | ผลลัพธ์ |
|---|---|---|---|
| `+` | บวก | `17 + 5` | `22` |
| `-` | ลบ | `17 - 5` | `12` |
| `*` | คูณ | `17 * 5` | `85` |
| `/` | หาร | `17 / 5` | `3` (!) |
| `%` | หารเอาเศษ (modulo) | `17 % 5` | `2` |

```java
public class Main {
    public static void main(String[] args) {
        int a = 17;
        int b = 5;
        System.out.println(a + b);
        System.out.println(a - b);
        System.out.println(a * b);
        System.out.println(a / b);
        System.out.println(a % b);
        System.out.println(17.0 / 5);
    }
}
```

```output
22
12
85
3
2
3.4
```

> ⚠️ **หารเลขจำนวนเต็มได้จำนวนเต็ม!** `17 / 5` ได้ `3` ไม่ใช่ `3.4` เพราะเมื่อ int หาร int ผลลัพธ์จะเป็น int และ **ตัดเศษทิ้ง** (ไม่ปัดเศษ) ถ้าต้องการทศนิยม ต้องให้อย่างน้อยหนึ่งตัวเป็น `double` เช่น `17.0 / 5` นี่คือบั๊กที่มือใหม่เจอบ่อยที่สุดเรื่องหนึ่ง

ส่วน `%` (หารเอาเศษ) ดูแปลกแต่มีประโยชน์มาก ใช้ตรวจเลขคู่-คี่ (`n % 2`) หรือตรวจว่าหารลงตัวไหม (`n % 3 == 0`) เราจะใช้มันอีกเยอะในบทถัดไป

### ทางลัดสำหรับเปลี่ยนค่าตัวแปร

| เขียนสั้น | ความหมาย |
|---|---|
| `x++` | `x = x + 1` (เพิ่มทีละ 1) |
| `x--` | `x = x - 1` (ลดทีละ 1) |
| `x += 5` | `x = x + 5` |
| `x -= 3` | `x = x - 3` |
| `x *= 2` | `x = x * 2` |

```java
public class Main {
    public static void main(String[] args) {
        int count = 0;
        count++;       // 1
        count++;       // 2
        count += 10;   // 12
        count -= 3;    // 9
        count *= 2;    // 18
        System.out.println(count);
    }
}
```

```output
18
```

ลำดับการคำนวณเหมือนคณิตศาสตร์: `* / %` ก่อน `+ -` และใช้วงเล็บเพื่อความชัดเจนเสมอ เช่น `(a + b) / 2`

## แปลงชนิดข้อมูล (Type Casting)

บางครั้งเราต้องเอาค่าชนิดหนึ่งไปใส่ตัวแปรอีกชนิดหนึ่ง กฎง่ายๆ คือ

- **จากเล็กไปใหญ่ทำได้เอง** เช่น `int` → `double` (ไม่มีข้อมูลหาย)
- **จากใหญ่ไปเล็กต้องสั่งเอง** เช่น `double` → `int` โดยใส่ `(int)` นำหน้า เพราะ **ทศนิยมจะถูกตัดทิ้ง** Java เลยให้เราตัดสินใจเองว่ายอมเสียข้อมูลจริงๆ

```java
public class Main {
    public static void main(String[] args) {
        int x = 7;
        double y = x;            // int -> double อัตโนมัติ
        System.out.println(y);

        double price = 3.99;
        int whole = (int) price; // double -> int ต้องใส่ (int) เอง ทศนิยมถูกตัดทิ้ง
        System.out.println(whole);

        System.out.println((double) 7 / 2);  // แปลง 7 เป็น 7.0 ก่อนหาร
    }
}
```

```output
7.0
3
3.5
```

บรรทัดสุดท้ายเป็นวิธีแก้กับดักการหารจำนวนเต็มที่พูดถึงไปข้างบน: แปลงตัวใดตัวหนึ่งเป็น `double` ก่อนหาร จะได้ผลลัพธ์เป็นทศนิยม

## รับข้อมูลจากผู้ใช้ด้วย Scanner

โปรแกรมที่น่าสนใจต้องโต้ตอบกับผู้ใช้ได้ Java ให้เครื่องมือชื่อ **`Scanner`** สำหรับอ่านข้อมูลที่ผู้ใช้พิมพ์เข้ามา ใช้ 3 ขั้นตอน

1. `import java.util.Scanner;` ที่บรรทัดบนสุด (บอก Java ว่าจะใช้เครื่องมือนี้)
2. `Scanner sc = new Scanner(System.in);` สร้างตัวอ่าน (ชื่อ `sc` ตั้งเองได้)
3. เรียกเมธอดอ่านข้อมูลตามชนิดที่ต้องการ

| เมธอด | อ่านอะไร |
|---|---|
| `sc.nextLine()` | ข้อความ **ทั้งบรรทัด** (รวมเว้นวรรค) |
| `sc.next()` | ข้อความ **1 คำ** (ตัดที่เว้นวรรค) |
| `sc.nextInt()` | จำนวนเต็ม |
| `sc.nextDouble()` | เลขทศนิยม |
| `sc.nextBoolean()` | `true` หรือ `false` |

```java stdin=Ploy
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String name = sc.nextLine();
        System.out.println("Hello, " + name + "!");
    }
}
```

```output
Hello, Ploy!
```

อ่านตัวเลขก็ทำเหมือนกัน แค่เปลี่ยนเมธอดให้ตรงกับชนิด

```java stdin=20%0A1.75
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int age = sc.nextInt();
        double height = sc.nextDouble();
        System.out.println("Age " + age + ", height " + height);
    }
}
```

```output
Age 20, height 1.75
```

### 🔑 วิธีป้อนข้อมูลในเว็บนี้ (สำคัญมาก!)

ถ้าคุณเคยรันโปรแกรมบนคอมพิวเตอร์ตัวเอง โปรแกรมจะหยุดรอให้เราพิมพ์ตอนเจอ `Scanner` แต่ **ในเว็บนี้เราต้องใส่ข้อมูลทั้งหมดล่วงหน้า** ในช่อง **Standard Input** ก่อนกดรัน แล้วโปรแกรมจะอ่านจากช่องนั้นตามลำดับ

> 💡 **กฎง่ายๆ:** โปรแกรมเรียกอ่านข้อมูลกี่ครั้ง ก็ใส่ข้อมูลตามลำดับนั้น **บรรทัดละค่า** เช่น โปรแกรมด้านบนอ่านอายุก่อนแล้วจึงอ่านส่วนสูง ในช่อง Standard Input ก็ต้องพิมพ์ 20 ขึ้นบรรทัดใหม่แล้วพิมพ์ 1.75

```input
20
1.75
```

- ถ้าช่อง Standard Input **ว่างหรือใส่ไม่ครบ** จะเกิด error `NoSuchElementException: No line found` (แปลว่า "โปรแกรมอยากอ่านอีก แต่ไม่มีข้อมูลให้แล้ว")
- ปุ่ม **▶ ลองรัน** ของตัวอย่างในบทเรียนนี้จะใส่ข้อมูลให้ในช่อง Standard Input อัตโนมัติ

### กับดักสุดคลาสสิก: `nextInt()` แล้วตามด้วย `nextLine()`

นี่คือเรื่องที่นักเรียนเกือบทุกคนต้องเจออย่างน้อยหนึ่งครั้ง ลองดูโปรแกรมนี้ที่ตั้งใจจะอ่านตัวเลข แล้วอ่านข้อความบรรทัดถัดไป

```java stdin=5%0Ahello
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        String text = sc.nextLine();   // คาดว่าจะได้ hello แต่...
        System.out.println("n=" + n + " text=[" + text + "]");
    }
}
```

```output
n=5 text=[]
```

`text` เป็นสตริงว่าง! โปรแกรมไม่ได้พัง และไม่มี error แต่ดูเหมือน "ไม่อ่านค่า" นี่คือสาเหตุ

```diagram
ข้อมูลที่พิมพ์:   5 [Enter] hello [Enter]
                  ^
nextInt() อ่านแค่เลข 5 แล้วหยุด  -->  ปุ่ม [Enter] หลังเลข 5 ยัง "ค้าง" อยู่
nextLine() อ่านต่อจากตรงนั้นจนถึง [Enter] --> ได้ข้อความว่าง ""
```

`nextInt()` อ่านเฉพาะตัวเลข แต่ **ไม่กินเครื่องหมายขึ้นบรรทัดใหม่** ที่ตามหลัง พอเรียก `nextLine()` ต่อ มันจึงอ่านส่วนที่เหลือของบรรทัดเดิม (ซึ่งว่างเปล่า) วิธีแก้คือ **เรียก `nextLine()` เพิ่มอีกหนึ่งครั้งเพื่ออ่านทิ้ง**

```java stdin=5%0Ahello
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        sc.nextLine();                 // อ่านทิ้ง 1 รอบ เพื่อกิน Enter ที่ค้างอยู่
        String text = sc.nextLine();   // ตอนนี้ได้ hello แล้ว
        System.out.println("n=" + n + " text=[" + text + "]");
    }
}
```

```output
n=5 text=[hello]
```

> 💡 **สรุปกฎจำง่าย:** ถ้าอ่านตัวเลข (`nextInt`, `nextDouble`) แล้วจะอ่านข้อความทั้งบรรทัด (`nextLine`) ต่อ ให้ใส่ `sc.nextLine();` คั่นกลางหนึ่งบรรทัดเสมอ แต่ถ้าอ่านตัวเลขอย่างเดียวติดกันหลายตัว (`nextInt` หลายครั้ง) ไม่ต้องทำอะไรพิเศษ

## ข้อผิดพลาดที่เจอบ่อย

ลองกดรันโค้ดนี้ จะเจอ error เพราะพยายามเอาทศนิยมใส่ตัวแปร `int`

```java expect=compile-error
public class Main {
    public static void main(String[] args) {
        int x = 3.5;
        System.out.println(x);
    }
}
```

| ข้อผิดพลาด | ข้อความ error | วิธีแก้ |
|---|---|---|
| ใส่ทศนิยมให้ `int` | `incompatible types: possible lossy conversion from double to int` | ใช้ `double` หรือ cast ด้วย `(int)` |
| ใช้ตัวแปรที่ยังไม่ประกาศ | `cannot find symbol` | ประกาศตัวแปรก่อนใช้ และตรวจตัวสะกด/ตัวพิมพ์ |
| ใช้ตัวแปรที่ยังไม่มีค่า | `variable x might not have been initialized` | ใส่ค่าให้ตัวแปรก่อนอ่านค่า |
| ลืม `import java.util.Scanner;` | `cannot find symbol ... class Scanner` | เพิ่ม `import` ไว้บรรทัดบนสุด |
| ใช้ `' '` ครอบข้อความยาว | `unclosed character literal` | `' '` ใช้กับ char 1 ตัว ข้อความใช้ `" "` |

## สรุปบทที่ 2

| เรื่อง | สิ่งที่ต้องจำ |
|---|---|
| ตัวแปร | กล่องมีป้ายชื่อ ใช้เก็บข้อมูล ค่าเปลี่ยนได้ ประกาศด้วย `ชนิด ชื่อ = ค่า;` |
| ชนิดข้อมูล | `int` เลขเต็ม, `double` ทศนิยม, `char` ตัวอักษร, `boolean` จริง/เท็จ, `String` ข้อความ |
| `=` | เอาค่าขวาไปเก็บในตัวแปรซ้าย (ไม่ใช่ "เท่ากับ") |
| ชื่อตัวแปร | camelCase, ห้ามขึ้นต้นด้วยตัวเลข, ห้ามซ้ำคำสงวน |
| หารจำนวนเต็ม | `int / int` ได้ `int` ตัดเศษทิ้ง ใช้ `double` ถ้าต้องการทศนิยม |
| casting | เล็กไปใหญ่ทำเอง ใหญ่ไปเล็กใส่ `(int)` |
| Scanner | `nextLine()` ทั้งบรรทัด, `nextInt()` เลขเต็ม, `nextDouble()` ทศนิยม |
| เว็บนี้ | ใส่ข้อมูลล่วงหน้าในช่อง Standard Input บรรทัดละค่า |
| `nextInt()` แล้ว `nextLine()` | ต้องคั่นด้วย `sc.nextLine();` อีกหนึ่งครั้ง |

ถัดไปลองทำแบบฝึกหัดการอ่านชื่อแล้วทักทายด้านล่างได้เลย
