## prompt

อ่าน **ชื่อ** จาก input หนึ่งบรรทัด แล้วพิมพ์คำทักทายในรูปแบบ `Hello, <ชื่อ>!`

**ตัวอย่าง**

| Input | ผลลัพธ์ที่ต้องได้ |
|---|---|
| `Ploy` | `Hello, Ploy!` |
| `Beam` | `Hello, Beam!` |

> 📝 จำได้ไหม? ปุ่ม **▶ รันทดสอบ** ใช้ค่าในช่อง Standard Input ที่คุณพิมพ์เอง ส่วนปุ่ม **✔ ส่งตรวจ** จะทดสอบกับ input ของโจทย์เอง (หลายชุด) ไม่ได้ใช้ค่าในช่องนั้น

## hint

โปรแกรมอ่านชื่อมาเก็บใน `name` ให้แล้ว ที่เหลือคือต่อข้อความด้วย `+` : `"Hello, " + name + "!"` (สังเกตว่าหลังเครื่องหมาย `,` มีเว้นวรรคหนึ่งตัว)

## explanation

```java run=no
System.out.println("Hello, " + name + "!");
```

- `sc.nextLine()` อ่านชื่อทั้งบรรทัดเก็บใน `name` (โค้ดตั้งต้นเตรียมไว้ให้แล้ว)
- เครื่องหมาย `+` ระหว่าง String กับตัวแปร คือการ **ต่อข้อความ** ได้เป็นประโยคเดียว
- `name` ไม่มีเครื่องหมายคำพูด เพราะเราต้องการ **ค่าในตัวแปร** ไม่ใช่คำว่า "name"
- ผลลัพธ์จึงเปลี่ยนไปตามที่ผู้ใช้ป้อน: ป้อน `Ploy` ได้ `Hello, Ploy!` ป้อน `Beam` ได้ `Hello, Beam!`

นี่คือรูปแบบ **รับค่า → ประมวลผล → แสดงผล** ที่โปรแกรมเกือบทุกตัวใช้
