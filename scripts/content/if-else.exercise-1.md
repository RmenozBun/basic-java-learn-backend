## prompt

อ่านจำนวนเต็มหนึ่งค่า ถ้าเป็น **เลขคู่** ให้พิมพ์ `Even` ถ้าเป็น **เลขคี่** ให้พิมพ์ `Odd`

**ตัวอย่าง**

| Input | ผลลัพธ์ที่ต้องได้ |
|---|---|
| `4` | `Even` |
| `7` | `Odd` |

## hint

เลขคู่คือเลขที่หารด้วย 2 ลงตัว (เศษเป็น 0) ใช้ตัวดำเนินการ `%` ตรวจ: `if (n % 2 == 0) { ... } else { ... }` อย่าลืมว่าเครื่องหมาย "เท่ากับ" ที่ใช้เปรียบเทียบคือ `==` (สองตัว)

## explanation

```java run=no
if (n % 2 == 0) {
    System.out.println("Even");
} else {
    System.out.println("Odd");
}
```

- `n % 2` คือเศษจากการหาร n ด้วย 2 ซึ่งมีได้แค่ 0 หรือ 1 (เลขลบอาจได้ -1 จึงไม่ควรเช็คว่า `== 1` แต่เช็ค `== 0` แล้วใช้ `else` รับที่เหลือจะปลอดภัยกว่า)
- เศษเป็น 0 แปลว่าหารลงตัว นั่นคือเลขคู่ จึงเข้า `if`
- นอกนั้นคือเลขคี่ จึงเข้า `else`
- ต้องมีทางใดทางหนึ่งทำงานเสมอ และทำแค่ทางเดียว ซึ่งเป็นลักษณะของ `if ... else`
