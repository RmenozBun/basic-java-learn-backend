หลังจบบทนี้ คุณจะ

- เข้าใจว่า Java คืออะไร และโปรแกรม Java ทำงานอย่างไร
- เขียนและรันโปรแกรมแรกของตัวเองได้
- รู้จักโครงสร้างพื้นฐานของโปรแกรม Java: `class`, `main`, `println`
- พิมพ์ข้อความหลายบรรทัด ใช้อักขระพิเศษ และเขียน comment ได้
- อ่านข้อความ error เบื้องต้นแล้วรู้ว่าต้องแก้ตรงไหน

> 📝 **วิธีเรียนบทนี้ให้ได้ผลที่สุด:** อย่าอ่านอย่างเดียว! ทุกกล่องโค้ดที่มีปุ่ม **▶ ลองรัน** ให้กดเข้าไปเล่นใน Playground แล้วลองแก้โค้ดดูว่าผลลัพธ์เปลี่ยนไปอย่างไร การพังบ้างคือส่วนหนึ่งของการเรียนเขียนโปรแกรม

## Java คืออะไร

**Java** คือภาษาโปรแกรมที่เกิดขึ้นในปี 1995 โดยทีมของ James Gosling ที่บริษัท Sun Microsystems (ปัจจุบันดูแลโดย Oracle) ปัจจุบันยังเป็นหนึ่งในภาษาที่คนใช้มากที่สุดในโลก ถูกใช้ทำระบบหลังบ้านขององค์กรและธนาคาร แอปพลิเคชัน Android เกม (เช่น Minecraft เวอร์ชัน Java) และอื่นๆ อีกมากมาย

จุดเด่นที่ทำให้ Java โด่งดังคือแนวคิด **"เขียนครั้งเดียว รันได้ทุกที่"** (Write Once, Run Anywhere) เพราะโปรแกรม Java ไม่ได้รันบนเครื่องคอมพิวเตอร์โดยตรง แต่รันบน **JVM (Java Virtual Machine)** ซึ่งเป็นเหมือนล่ามที่มีให้ทุกระบบปฏิบัติการ โค้ดเดียวกันจึงรันได้ทั้ง Windows, macOS และ Linux

## โปรแกรม Java ทำงานอย่างไร

เวลาเราเขียนโปรแกรม Java จะมี 3 ขั้นตอนหลัก

```diagram
Main.java  --(javac: compile)-->  Main.class  --(java: JVM)-->  Output
 (source)                         (bytecode)                  (result)
```

1. **เขียนโค้ด** เราเขียนโค้ดที่มนุษย์อ่านรู้เรื่องลงในไฟล์ `.java` (เรียกว่า *source code*)
2. **คอมไพล์ (compile)** ตัวแปลภาษาชื่อ `javac` จะแปลง source code ให้เป็น *bytecode* ในไฟล์ `.class` ถ้าโค้ดเขียนผิดไวยากรณ์ จะหยุดตรงนี้และแจ้ง error ให้เรา
3. **รัน (run)** JVM อ่าน bytecode แล้วสั่งให้คอมพิวเตอร์ทำงานตามนั้น

> 💡 **ในเว็บนี้ไม่ต้องติดตั้งอะไรเลย** เมื่อกดปุ่ม "รัน" ระบบจะส่งโค้ดของคุณไปคอมไพล์และรันให้ แล้วส่งผลลัพธ์กลับมาแสดงให้ดู ทำงานครบ 3 ขั้นตอนข้างบนในไม่กี่วินาที

## โปรแกรมแรก: Hello, World!

ธรรมเนียมของนักเขียนโปรแกรมทั่วโลก โปรแกรมแรกที่เขียนจะพิมพ์คำว่า Hello, World! ออกหน้าจอ ลองกด **▶ ลองรัน** ดูเลย

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

```output
Hello, World!
```

### แกะโค้ดทีละบรรทัด

โค้ดแค่ 5 บรรทัด แต่มีหลายอย่างให้เรียนรู้ มาแกะดูทีละส่วนกัน

| บรรทัด | โค้ด | ความหมาย |
|---|---|---|
| 1 | `public class Main {` | ประกาศ **คลาส** (class) ชื่อ `Main` โค้ด Java ทุกอย่างต้องอยู่ในคลาส คิดว่าคลาสเป็น "กล่อง" ที่ห่อโปรแกรมของเราไว้ |
| 2 | `public static void main(String[] args) {` | ประกาศ **เมธอด `main`** ซึ่งเป็น **จุดเริ่มต้น** ของโปรแกรม เมื่อรันโปรแกรม Java จะเริ่มทำงานจากบรรทัดแรกใน `main` เสมอ |
| 3 | `System.out.println("Hello, World!");` | คำสั่ง **พิมพ์ข้อความ** ออกหน้าจอ แล้วขึ้นบรรทัดใหม่ |
| 4 | `}` | ปิดเมธอด `main` |
| 5 | `}` | ปิดคลาส `Main` |

ตอนนี้ยังไม่ต้องเข้าใจคำว่า `public`, `static`, `void`, `String[] args` ทั้งหมดก็ได้ครับ ให้ท่องไว้ก่อนว่า **"โปรแกรมของเราทุกอันขึ้นต้นด้วยโครงนี้"** แล้วเราจะค่อยๆ เข้าใจทีละคำในบทหลังๆ

มี 3 กฎสำคัญที่ต้องจำตั้งแต่วันนี้

1. **ปีกกา `{ }` คือขอบเขต** ทุกครั้งที่เปิด `{` ต้องมี `}` ปิดคู่กันเสมอ สิ่งที่อยู่ในปีกกาคือ "ของที่อยู่ข้างใน" คลาสหรือเมธอดนั้น
2. **ทุกคำสั่งต้องจบด้วย `;` (semicolon)** เหมือนจุดท้ายประโยคในภาษาไทย คอมไพเลอร์ใช้มันเพื่อรู้ว่าคำสั่งนี้จบแล้ว
3. **Java แยกตัวพิมพ์เล็ก-ใหญ่** `System` กับ `system` คือคนละคำกัน

> ⚠️ **ในเว็บนี้ ชื่อคลาสต้องเป็น `Main` เสมอ** เพราะระบบรันโค้ดจะมองหาคลาสชื่อนี้ ถ้าเปลี่ยนชื่อ โปรแกรมจะรันไม่ขึ้น

## พิมพ์ข้อความ: `print` กับ `println`

`System.out` คือ "หน้าจอ" ส่วน `println` มาจาก *print line* แปลว่า พิมพ์แล้วขึ้นบรรทัดใหม่ ถ้าไม่อยากขึ้นบรรทัดใหม่ให้ใช้ `print`

```java
public class Main {
    public static void main(String[] args) {
        System.out.print("Hello ");
        System.out.print("Java");
        System.out.println("!");
        System.out.println("Next line");
    }
}
```

```output
Hello Java!
Next line
```

สังเกตว่าสามบรรทัดแรกต่อกันเป็นบรรทัดเดียว เพราะ `print` ไม่ขึ้นบรรทัดใหม่ จนกระทั่งถึง `println("!")` ที่พิมพ์เครื่องหมาย ! แล้วจึงขึ้นบรรทัดใหม่ บรรทัดสุดท้ายจึงอยู่คนละบรรทัด

> 📝 ข้อความที่ต้องการพิมพ์ต้องอยู่ใน **เครื่องหมายคำพูดคู่ `" "`** เสมอ เรียกว่า *String literal* ถ้าลืมปิดเครื่องหมายคำพูด คอมไพเลอร์จะฟ้อง error ทันที

## อักขระพิเศษ (Escape Sequences)

บางครั้งเราอยากพิมพ์สิ่งที่พิมพ์ตรงๆ ไม่ได้ เช่น ขึ้นบรรทัดใหม่กลางประโยค หรือพิมพ์เครื่องหมายคำพูด `"` (เพราะ `"` ถูกใช้เป็นตัวบอกขอบเขตข้อความแล้ว) Java จึงมีรหัสพิเศษที่ขึ้นต้นด้วย `\` (backslash)

| รหัส | ความหมาย |
|---|---|
| `\n` | ขึ้นบรรทัดใหม่ |
| `\t` | เว้นระยะแบบ tab |
| `\"` | พิมพ์เครื่องหมายคำพูด `"` |
| `\\` | พิมพ์เครื่องหมาย `\` |

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Line 1\nLine 2");
        System.out.println("She said \"Hi\"");
        System.out.println("C:\\Users\\Ploy");
    }
}
```

```output
Line 1
Line 2
She said "Hi"
C:\Users\Ploy
```

## Comment: ข้อความที่คอมพิวเตอร์ไม่อ่าน

**Comment** คือหมายเหตุที่เราเขียนไว้ให้ *คนอ่าน* คอมไพเลอร์จะข้ามไปทั้งหมด ใช้อธิบายว่าโค้ดส่วนนี้ทำอะไร หรือปิดโค้ดชั่วคราวระหว่างทดลอง

```java
public class Main {
    public static void main(String[] args) {
        // comment บรรทัดเดียว: ขึ้นต้นด้วย // จนจบบรรทัด
        System.out.println("Visible");

        /* comment หลายบรรทัด
           เขียนอธิบายยาวๆ ได้
           จนกว่าจะเจอเครื่องหมายปิด */
        System.out.println("Also visible");

        // System.out.println("This line is switched off");
    }
}
```

```output
Visible
Also visible
```

บรรทัดสุดท้ายถูก comment ไว้ จึงไม่ถูกรัน เทคนิคนี้ใช้บ่อยมากตอนทดลองหรือหาที่ผิดในโค้ด

## ข้อผิดพลาดที่เจอบ่อยสำหรับมือใหม่

ทุกคนเจอ error ตอนเขียนโค้ด แม้แต่โปรแกรมเมอร์มืออาชีพ! ทักษะสำคัญคือ **อ่านข้อความ error ให้เป็น** ข้อความ error ของ Java จะบอกชื่อไฟล์ **เลขบรรทัด** และสาเหตุเสมอ ลองกดรันโค้ดข้างล่างนี้ดู (ตั้งใจให้ลืม `;`)

```java expect=compile-error
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello")
    }
}
```

คุณจะเจอข้อความประมาณว่า `error: ';' expected` พร้อมลูกศรชี้ตำแหน่ง ซึ่งแปลว่า "ตรงนี้ควรมี ; แต่ไม่เจอ"

| อาการ | ข้อความ error ที่มักเจอ | วิธีแก้ |
|---|---|---|
| ลืมใส่ `;` ท้ายคำสั่ง | `';' expected` | เติม `;` ที่ท้ายบรรทัดที่ error (หรือบรรทัดก่อนหน้า) |
| พิมพ์ `system` ตัวเล็ก | `package system does not exist` | แก้เป็น `System` ตัว S ใหญ่ |
| ลืมปิดเครื่องหมายคำพูด | `unclosed string literal` | ปิดข้อความด้วย `"` ให้ครบคู่ |
| ลืมปิดปีกกา | `reached end of file while parsing` | นับปีกกา `{` และ `}` ให้เท่ากัน |

> 💡 **เคล็ดลับ:** error แรกคือตัวที่สำคัญที่สุด บางครั้งโค้ดผิดจุดเดียวแต่เกิด error เป็นสิบบรรทัด เพราะคอมไพเลอร์งงต่อเนื่อง แก้ error แรกแล้วรันใหม่ error ที่เหลือมักหายไปเอง

## สรุปบทที่ 1

| เรื่อง | สิ่งที่ต้องจำ |
|---|---|
| โครงโปรแกรม | `public class Main { public static void main(String[] args) { ... } }` |
| พิมพ์ข้อความ | `System.out.println("...")` (ขึ้นบรรทัดใหม่) และ `System.out.print("...")` (ไม่ขึ้นบรรทัดใหม่) |
| จบคำสั่ง | ใส่ `;` เสมอ |
| ขอบเขต | ปีกกา `{ }` ต้องเปิด-ปิดเป็นคู่ |
| ตัวพิมพ์ | `System` ≠ `system` |
| อักขระพิเศษ | `\n` ขึ้นบรรทัดใหม่, `\"` เครื่องหมายคำพูด, `\\` backslash |
| Comment | `//` บรรทัดเดียว, `/* ... */` หลายบรรทัด |

พร้อมแล้วก็ลงมือทำแบบฝึกหัดข้างล่างได้เลย ไม่ต้องกลัวผิด กดรันทดสอบกี่ครั้งก็ได้
