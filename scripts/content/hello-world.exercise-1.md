## prompt

เขียนโปรแกรมที่พิมพ์ข้อความ `Hello, Java!` ออกทางหน้าจอ

**ตัวอย่างผลลัพธ์**

```output
Hello, Java!
```

พิมพ์โค้ดไว้ในบรรทัดที่มี comment บอกไว้ในช่องโค้ดด้านล่าง แล้วกด **▶ รันทดสอบ** เพื่อดูผลลัพธ์ก่อน เมื่อมั่นใจแล้วค่อยกด **✔ ส่งตรวจ**

## hint

ใช้คำสั่ง `System.out.println(...)` แล้วใส่ข้อความที่ต้องการพิมพ์ไว้ใน **เครื่องหมายคำพูดคู่** `" "` อย่าลืมปิดท้ายคำสั่งด้วย `;`

## explanation

```java run=no
System.out.println("Hello, Java!");
```

- `System.out.println` คือคำสั่งพิมพ์ข้อความแล้วขึ้นบรรทัดใหม่
- ข้อความอยู่ใน `" "` เพราะเป็น String literal (ข้อความตรงๆ) ไม่ใช่ชื่อตัวแปร
- ท้ายคำสั่งต้องมี `;` เสมอ
- คำสั่งนี้ต้องเขียนอยู่ **ข้างใน** `main` (ระหว่างปีกกาของ `main`) เพราะ Java เริ่มทำงานจากที่นั่น

**ข้อสังเกต:** ระบบตรวจคำตอบเทียบผลลัพธ์แบบไม่สนตัวพิมพ์เล็ก-ใหญ่และเครื่องหมายวรรคตอน แต่ในการเขียนโปรแกรมจริง ควรพิมพ์ให้ตรงตามโจทย์เสมอ
